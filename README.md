# سِدرا — آتلیه لپ‌تاپ‌های پریمیوم

سایت لندینگ پرمیوم برای برند سِدرا، آتلیه انتخاب‌شده لپ‌تاپ‌های خلاق در تهران.

## درباره

سِدرا ترکیبی از معماری مینیمال، تایپوگرافی فارسی و تجربه کاربری لوکس است. طراحی شده بدون فریم‌ورک، با HTML، CSS و جاوااسکریپت خالص برای سازگاری کامل با GitHub Pages.

## ویژگی‌ها

- طراحی RTL و فارسی کامل با فونت Vazirmatn
- انیمیشن‌های نرم اسکرول و تعاملات ریز (micro-interactions)
- تصاویر محلی تولیدشده برای برند
- واکنش‌گرا برای دسکتاپ و موبایل
- دسترسی‌پذیری: نقش‌های ARIA، متن جایگزین و کنتراست بالا

## فناوری

- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Vazirmatn)
- تصاویر محلی در پوشه `images/`
- بهینه برای GitHub Pages

## مجوز

تمامی حقوق برای برند سِدرا محفوظ است.
